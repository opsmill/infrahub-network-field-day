The data centre fabric

Arista switches in a spine and leaf design. The two spines are spine1 and spine2, and the leaves include k8s-leaf1, k8s-leaf2, app-leaf1, app-leaf2 and border-leaf1. The fabric runs BGP with EVPN.

The firewall

fw1 is a Junos firewall. Every path between two networks crosses it, in a zone pair such as branch to k8s-prod.

The WAN

Two provider edge routers, isp-pe1 and isp-pe2, run SR Linux in AS 65500. Each tenant gets one VRF on them.

The Kubernetes cluster

Cilium advertises each application's virtual IP address to the fabric over BGP. Applications run in this cluster.

Where the intent lives

Infrahub holds the intended state. Generators build the technical objects from a request, transforms render the configurations, and a reconciler compares each device with its rendered configuration and pushes any difference.
