2026-10-07: repository sync stalled for about 90 minutes

Cause: a dead task worker still held the concurrency slot for the repository-sync flow.

Fix: the stuck workflow runs were marked crashed, two concurrency slots were released, both task workers were restarted, and stale branch copies were removed from the workers.

2026-10-07: two DNS generator runs created the same address

Cause: the application's creation and the arrival of its address block each started the generator, and both created the same address. The unique constraint holds at merge, not at write, so the branch could not merge.

Fix: the generator names the namespace when it creates the address, and every run removes duplicates and keeps the lowest id.

2026-10-07: nslookup reported a name missing that the resolver answered

Cause: the resolver did not set the recursion-available flag, and nslookup discards a reply without it.

Fix: the zone block sets the flag.
