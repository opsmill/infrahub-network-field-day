An OTTERNET web service, and the network path that carried you to it

The path from the branch office

branch-desktop→ branch-rtr→ border-leaf1→ fw1 (zone branch to zone k8s-prod)→ border-leaf1→ spines→ k8s-leaf→ Kubernetes node→ this pod

Three gates decide whether you reached this page

  1. The route. The cluster advertises this application's virtual IP address to the fabric over BGP, from the nodes that run its pods.
  2. The firewall. A rule on fw1 permits your source network to reach the virtual IP address on TCP port 80.
  3. The pod policy. A Cilium network policy admits only the source prefixes the application was granted.
