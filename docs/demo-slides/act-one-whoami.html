Running

Eleven stages inside step 2

Each stage writes a line to the log, then how long it took. A failure names the stage and shows Infrahub's own error.

1/11 Create the branch implement_otter-shop_demo1
2/11 Read the application's catalogue entry requestable and active, checked again
3/11 Create the application as alice
4/11 Wait for the VIP block to be allocated
5/11 Read the allocated block
6/11 Prove the block exists before granting access to it
7/11 Create the access grant alice is the requester
8/11 Wait for the firewall objects
9/11 Find the AVD generators
10/11 Regenerate the host vars for every switch
11/11 Regenerate the structured configs 21 to 25 s for stages 10 and 11

Stages 4 to 6 exist because the grant needs the address block, and nothing else orders the two generators. A grant created too early is marked error and is not retried.
